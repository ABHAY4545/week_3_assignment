# Project instructions

## Browser preference
- Use Codex's built-in in-app browser (`iab`) for browser work and UI verification.
- Do not open or control personal browsers unless the user explicitly requests one.

## UI preferences
- This is an assignment demo. Keep the interface minimal and focused on the RAG demonstration.
- Do not use arrow icons, arrow glyphs, chevrons, or triangular disclosure markers anywhere in the project UI.
- Use plain text actions and plus/minus disclosure indicators where needed.
- Avoid decorative cards, rectangular boxes, or borders around text. Keep boundaries only where they clarify an input or separate content.
- Keep keyboard focus visible using an underline or another unobtrusive indicator; do not add large rectangular outlines around text controls or source entries.
- Use a shared alignment grid for the header, composer, and results. Submitting a question must not shift the composer sideways.
